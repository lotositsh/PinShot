# 📷 Screenshot Mini

A tiny, always-on-top Windows screenshot tool. Click the floating icon (or hit a global hotkey), drag to select a region, then upload it to [imgbb](https://imgbb.com/) or copy it straight to your clipboard — the URL lands on your clipboard automatically after upload.

## Features

PinShot is a simple program that allows you to take a screenshot and send it to https://imgbb.com/
It requires an API key, which you can get here https://api.imgbb.com/
The program immediately copies the link to the clipboard after sending.
To take a screenshot, click the program icon or press ctrl+alt (by default).

## Settings
Supports multiple formats and the ability to compress images to reduce the screenshot size.
Select the screenshot storage time.
